HÀNH TINH XANH V25 - CHECKLIST ĐƯA WEBSITE ONLINE

1. Push toàn bộ source V25 lên GitHub.
2. Tạo Firebase Project.
3. Bật Cloud Firestore.
4. Bật Firebase Authentication.
5. Tạo Firebase Web App.
6. Deploy firestore.rules.
7. Import GitHub repo vào Vercel.
8. Vercel > Settings > Environment Variables: nhập đầy đủ Firebase Admin + Firebase Web config.
9. Redeploy.
10. Mở /api/health: phải trả ok:true.
11. Đăng nhập giamdoc / 123456.
12. Thanh trên phải hiện Realtime đang hoạt động.
13. Mở 2 máy khác nhau, tạo/chỉnh đơn và kiểm tra cập nhật ngay.
